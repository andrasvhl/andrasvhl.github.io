Task Loop

From a brain dump to a planned week.

Four Claude Code skills that turn whatever is in your head into tasks, decide what actually matters, and fit it into your calendar.

Download Task Loop ↓ Free · MIT licence · README inside
01

What it does

Dump

Say everything on your mind. It is captured word for word, with a quick sweep for what you forgot.

Commit

Claude proposes concrete tasks from the dump, each with a physical next step. Nothing is written until you approve.

Prioritise

You decide what matters, and the skill enforces the caps, so not everything can be top priority.

Schedule

It reads your calendar, states the gap in hours, protects deep work, and writes the blocks once you agree.

02

How it works

  1. Tasks are plain Markdown notes in a folder, with a small, fixed set of properties.
  2. A North Star note holds what matters this quarter. Prioritising reads it first.
  3. A working-conditions note holds your capacity and energy, so plans fit real days.
  4. Each skill does one job and stops, so you stay in charge between steps.
03

What you need

  • Claude Code
  • A folder of Markdown notes (Obsidian works well)
  • Optional: Google Calendar for scheduling
