Canvas Archive

Every course you have taken, searchable forever.

Pulls every Canvas course into your notes before access runs out: pages, assignments, files and your own submissions, with the text of every document extracted so Claude can answer questions about it.

01

What it does

Everything, verbatim

Modules, pages, assignments, rubrics, announcements, discussions and every downloadable file.

Text you can ask about

Every PDF, slide deck and spreadsheet gets its text extracted, so “what did week 3 cover?” just works.

Your own work kept

Your submissions and grades sit next to the course they belong to.

Incremental

The first run backfills everything. After that it only fetches what changed.

02

How it works

  1. Create a Canvas access token in your account settings.
  2. Run the archive once for the full backfill.
  3. Re-run whenever you like; it picks up only what is new.
  4. Ask Claude about any course, reading or assignment.
03

What you need

  • Claude Code
  • Python 3
  • A Canvas account (built for Stanford, works with any Canvas school)
  • Optional: Obsidian to browse it
